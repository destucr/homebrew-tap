# homebrew-tap

```sh
brew install --cask destucr/tap/switchboard
```

Casks: [Switchboard](https://github.com/destucr/Switchboard), a menu bar app showing every local port with its project.

```sh
brew install --cask destucr/tap/keypause
```

Casks: [Keypause](https://github.com/destucr/Keypause), a menu bar app that locks the keyboard while you clean it.
